## Возможности

### Прокси для Telegram
* Поднимает локальный прокси на телефоне (`127.0.0.1:1443`).
* Маскирует трафик Telegram под обычный HTTPS WebSocket для обхода блокировок.
* Автоматически находит рабочий сервер и запоминает его для быстрого подключения.

### VPN (Cloudflare WARP)
* Работает через Amnezia WireGuard с защитой от блокировок провайдерами (через него работают Discord и YouTube).
* Генерация и смена конфигурации WARP прямо в приложении в один клик.

### Звонки в Telegram
* Отдельный переключатель на главном экране: можно пускать звонки через туннель WARP или напрямую. (рекомендую через WARP)

### Раздельное туннелирование
* Два режима: пускать через VPN только выбранные приложения или, наоборот, исключить нужные (например, российские банки и Госуслуги).

### DNS
* Встроенные профили Comss.one, Cloudflare и Google с проверкой пинга.
* Через DNS обходятся блокировки ChatGPT и Gemini.

## Установка и обновления

1. Перейдите в раздел [Releases](https://github.com/KupTech/KupWS-apk/releases/latest).
2. Скачайте и установите файл **`KupWs.apk`**.
3. Приложение умеет обновляться само: при выходе новых версий появится предложение обновиться в один клик. Проверить обновления можно ручками на главной странице. Кнопка "Проверить обновления".
